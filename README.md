# Trees & Tails — Luxury Pet Resort V2

Premium static website for GitHub Pages.

## Files
- index.html
- style.css
- script.js

## Publish free
1. Create a **Public** repository on GitHub, e.g. `trees-and-tails`.
2. Upload the three files to the repository root.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Choose `main` and `/ (root)`.
6. Save.
7. Your site will appear at `https://YOUR-USERNAME.github.io/trees-and-tails/`.

## Before launch
The visual gallery uses sample Unsplash photography. Replace these image URLs with the resort's own photos for a fully authentic brand site. Confirm current business contact details, address, hours, review count and social links before publishing.
